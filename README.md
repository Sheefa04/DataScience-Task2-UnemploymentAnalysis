# OIBSIP Data Science Task 2 – Unemployment Analysis with Python

## 📌 Project Overview

This project is completed as part of the OASIS INFOBYTE Data Science Internship.

The objective of this project is to analyze unemployment data in India using Python and identify regional, monthly, and COVID-19 related trends.

## 🎯 Objectives

- Analyze unemployment rates across different regions.
- Study month-wise unemployment trends.
- Visualize unemployment rates for selected major states.
- Identify the top 10 regions with the highest average unemployment rate.
- Analyze the relationship between unemployment rate, employment, and labour participation rate.
- Compare unemployment levels before and after the COVID-19 period.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis Performed

1. Dataset loading and inspection
2. Data cleaning and date conversion
3. Region-wise average unemployment analysis
4. Month-wise unemployment trend analysis
5. State-wise time-series analysis
6. Top 10 regions by average unemployment rate
7. Correlation analysis
8. Correlation heatmap
9. Pre-COVID vs Post-COVID comparison
